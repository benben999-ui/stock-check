Check
Personal concept project · interactive demo One scan instead of six steps across two systems

When a picker reaches an empty pick slot, a certifier checks whether product is anywhere else in the building. Today that means copying codes between a route program and two pages of an inventory website, and then turning the product off by hand. This prototype puts the whole check on one screen.

Today: 6 steps, 2 systems

  1. Find the product in the route program
  2. Copy its product code
  3. Paste it into the inventory site to get a second code
  4. Paste that code into another page to see reserve stock
  5. Tell the picker where to go, or
  6. Go back and turn the product off

Prototype: 1 scan

  1. Scan or type the code and press Enter
  2. Read the location aloud, or press Turn off product and confirm the EMPTY SLOT step
